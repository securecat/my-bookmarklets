# アクセシビリティ

最終更新：2026-11-07

## 優先事項と目標

このリポジトリは、ほかの人が作ったウェブサイトの上で実行して、手間や使いにくさを減らすためのブックマークレット集です。店舗を1つずつ選んで確かめるしかない在庫検索を一度に済ませる（kinotento）、サイトが禁止している文字の選択・コピー・右クリックをできるようにする（unlock）、といった小さな道具ですが、どれも「サイトがそうなっているから仕方ない」と我慢していた困りごとを減らすためのものです。

たとえば、同じ操作を何十回も繰り返さなければならないページは、キーボードやスイッチで操作している人、画面を拡大している人にとって大きな負担になります。また、文字を選択できないページでは、選んだ文字を読み上げる機能や、翻訳・辞書などのツールが使えません。こうしたブックマークレットが、かえって別の人の使いにくさを生まないように気をつけています。

この文書が対象とするのは、次のとおりです。

- ブックマークレットを登録するためのインストールページ
- 各ブックマークレットが、実行したページに表示する画面（kinotento の結果パネル）
- 各ブックマークレットが、実行したページの見た目と操作に与える影響

ブックマークレットを実行する対象サイトそのもののアクセシビリティや、ブラウザのブックマークの機能は対象外です。

インストールページと、ブックマークレットがページに加える画面や変更は、WCAG 2.2 のレベル AA を目標とし、これを上限ではなく下限と考えています。AAより厳しい独自の基準もあります（[貢献者への期待](#貢献者への期待)を参照）。第三者による試験は受けていないため、これは目標であり、適合を表明するものではありません。

## 各ブックマークレットがページに加える変更

### kinotento

- 紀伊國屋書店ウェブストアの「店頭在庫検索」の画面で実行すると、画面の右上に結果パネルを重ねて表示します
- 全店舗の在庫を順に問い合わせ、「在庫あり」「在庫僅少」の店舗だけを一覧にします。調べ終わった店舗の数と、見つかった店舗は、調べ終わったものから順にパネルに追加されます。すべて調べ終わると、パネルの見出しが「在庫あり／僅少 店舗一覧（件数）」に変わります
- 店舗選択のフォームが見つからないページで実行したときは、ダイアログでお知らせします

### unlock

- 文字の選択・コピー・右クリックを妨げる処理を解除します。選んだ文字を読み上げる機能や、翻訳・辞書などのツールに文字を渡しやすくなります
- そのために、ページのすべての要素で文字を選択できるようにし、マウスボタンを押す操作・文字の選択・コピー・右クリック・キーを押す/離す操作が、ページ側の処理に届かないようにします。実行したあとで追加された要素や、Shadow DOM の中の要素（開いているもの）にも適用します
- 効果は、ページを再読み込みするまで続きます

## 対応している環境

- ブラウザ：Google Chrome、Microsoft Edge で動作を確認済み。Firefox、Safari では、まだ試していません
- OS：Windows で動作を確認済み。macOS などほかの OS では、まだ試していません
- スクリーンリーダー：まだ試していません
- インストールページは、キーボードだけで操作できます。ブックマークバーへのドラッグ&ドロップにはマウスが必要ですが、代わりに「コードをコピー」ボタンでコードをコピーし、ブラウザのブックマークの登録画面に URL として貼り付けて登録できます
- ブックマークレットは、ブラウザのブックマークの機能から実行します。キーボードでの実行のしかたは、ブラウザによって異なります。kinotento の結果パネルには、操作する部品はありません

## 既知の制限

- **kinotento の結果パネルには、閉じるボタンがありません。** ページを再読み込みするまで画面の右上に表示されたままで、その下にあるページの内容を覆います。画面を拡大していると、覆われる範囲が大きくなります。
  - 回避策：結果を確認し終えたら、ページを再読み込みしてください。
- **kinotento の進み具合や、調べ終わったことは、スクリーンリーダーに伝わりません。** 結果パネルはページの末尾に追加され、フォーカスも移らず、内容が変わったことも通知しないためです。
  - 回避策：実行してから少し待ち、ページの末尾にある結果パネルを読んでください。見出しが「在庫あり／僅少 店舗一覧」に変わっていれば、調べ終わっています。
- **kinotento の結果パネルの文字は、13px と小さめです。** また、文字色を指定していないため、白い背景に対する文字のコントラストは、サイト側の文字色に左右されます。ダークテーマにも対応していません。
  - 回避策：ブラウザの拡大機能で、ページごと大きくしてください。
- **unlock を実行すると、サイト独自のキー操作やマウス操作が効かなくなることがあります。** 禁止を解除するために、キーを押す・離す操作とマウスボタンを押す操作が、ページ側の処理に届かないようにしているためです。Tab キーでの移動や文字の入力など、ブラウザ標準の操作はそのまま使えますが、サイトが独自に用意している操作（Esc キーでダイアログを閉じる、矢印キーでメニューを移動する、入力欄に候補を表示する、など）は動かない場合があります。
  - 回避策：その操作が必要になったら、ページを再読み込みしてください。unlock の効果はなくなります。
- **unlock を実行しても、禁止を解除できないサイトがあります。** 透明な要素で文字を覆っている場合、文字を画像にしている場合、`<iframe>` の中の文字、閉じている Shadow DOM の中の文字などは対象外です。
  - 回避策：解除できなかったサイトがあれば、GitHub Issues でお知らせください。

## アクセシビリティの問題を報告する

問題は [GitHub Issues](https://github.com/securecat/my-bookmarklets/issues) で報告してください。日本語でも英語でも構いません。

次のことを書いてもらえると助かりますが、どれも任意です。

- 何をしようとしていたか
- 使っていたブックマークレットと、実行したページのURL（インストールページの問題なら、その旨）
- 何が起きたか、どうなると思っていたか
- OS、ブラウザのバージョン、ブックマークレットのバージョン（インストールページに表示しています）
- 使っている支援技術（スクリーンリーダーなど）

障害の有無や内容を書く必要はありません。スクリーンショットや録画も必須ではありません。

## 対応の流れ

このブックマークレット集は個人で開発しているため、返信や修正の期限はお約束できません。それでも、できるかぎり早く対応します。

- 報告を確認したら、Issue で返信します
- 回避策があれば、お知らせします
- 修正をリリースする前に、問題が解消したかどうかの確認をお願いすることがあります
- 修正したブックマークレットは、`@version` の番号を上げます。変更の内容は、コミット履歴で確認できます

## 貢献者への期待

ここに挙げることは、人間の貢献者にもコーディングエージェントにも、同じように求めます。

インストールページと、ブックマークレットがページに表示する画面（kinotento の結果パネルなど）を変更するときは、次を守ってください。

- フォームにはネイティブの要素（`<input>`・`<select>`・`<textarea>`）を使う。`<div>` や `<span>` をボタンの代わりにしない。画面内の操作には `<button>`、ページの移動には `<a>` を使う
- `disabled` 属性を使わない
- フォーカスインジケーターを消さない（`outline: none` を使わない）
- リンクの下線を消さない
- テキストのコントラスト比は、本文で 7:1 以上、補足的なテキストで 4.5:1 以上にする。ライトテーマとダークテーマのそれぞれで満たす
- 境界線やアイコンなど、テキスト以外の要素も、隣り合う色に対して 3:1 以上にする
- コントラストが必要な要素に `opacity` を使わない
- 文字サイズは、日本語で 16px 以上、英語で 14px 以上にする
- `font-family` は `sans-serif` にする（`system-ui` は使わない）
- ステータスメッセージを自動で消さない
- 自動スクロールなど、ひとりでに動くものを作らない

変更したあとは、キーボードだけですべて操作できること、スクリーンリーダーで内容が正しく読み上げられることを確認してください。ブックマークレットの場合は、実行した状態の対象サイトで確認してください。

ブックマークレットは、ほかの人が作ったサイトに後から手を加えるものです。そのため、次のことも守ってください。

- ページに画面を追加するときは、文字色・背景色・文字サイズ・`font-family` を明示し、対象サイトのスタイルに左右されないようにする
- ページに追加した画面には、閉じる手段を用意する
- 処理の進み具合や結果は、`role="status"` などを使って、スクリーンリーダーにも伝わるようにする
- キーボードのイベントを、必要な範囲を超えて止めたり横取りしたりしない
- 要素を隠すときは、その中にあったリンクや情報に、別の経路でたどり着けることを確かめる

インストールページは、`scripts/build-pages.mjs` が `bookmarklets/` のファイルから生成しています。インストールページを変更するときは、生成された `dist/index.html` ではなく、`scripts/build-pages.mjs` を直してください。
