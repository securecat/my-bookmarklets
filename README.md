# My Bookmarklets

個人的なブックマークレット集です。誰かの役に立つかもしれないということで公開しておきます。

## Installation

[インストールページ](https://securecat.github.io/my-bookmarklets/)を開き、各ブックマークレット名のリンクをブラウザのブックマークバーへドラッグ&ドロップしてください。

ドラッグができない場合は、各 `.js` ファイルの内容に`Javascript:`スキームをつけて、ブラウザのブックマークのURLとしてください。

## Bookmarklets

### kinotento

紀伊国屋書店ウェブストアの店頭在庫在庫検索はとても便利で貴重な機能ですが、調べるのがかなり面倒なので作りました。このブックマークレットを日本地図の画面で実行すれば、全店舗での在庫を調べて、店舗一覧の各店舗に結果を表示し、在庫のある店舗へのリンクを一覧の手前にまとめます。

[Install / View](./bookmarklets/kinotento.js)

### unlock

サイトが仕込んでいるコピー・右クリック・テキスト選択の禁止を解除します。動的に追加される要素やShadow DOMにも対応しています。

[Install / View](./bookmarklets/unlock.js)
